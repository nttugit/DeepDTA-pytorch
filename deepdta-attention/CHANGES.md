# CHANGES — DeepDTA-Attention vs original CNN–CNN

Fork of `deepdta/`. Goal: let the SMILES stream and the protein stream **talk to each other** before pooling, instead of only concatenating two independent vectors.

## Architecture

Original (`deepdta/model.py`):

```
SMILES  → Embed → 3×Conv1d → GlobalMaxPool ─┐
Protein → Embed → 3×Conv1d → GlobalMaxPool ─┴→ concat → FC
```

The two CNNs never mix features.

This fork (`model.py`):

```
SMILES  → Embed → 3×Conv1d → feature map (B, 3n, L_smi)
Protein → Embed → 3×Conv1d → feature map (B, 3n, L_prot)
        ↓
Bidirectional MultiheadAttention
  drug  = LN(drug  + MHA(Q=SMILES, K=protein, V=protein))
  prot  = LN(prot  + MHA(Q=protein, K=SMILES, V=SMILES))
        ↓
GlobalMaxPool each stream → concat → same FC head (1024 / 1024 / 512 / 1)
```

- `nn.MultiheadAttention` is the PyTorch counterpart of Keras `MultiHeadAttention`.
- Padding (token id 0) is masked (`key_padding_mask`). The pad mask is shortened by `3*(kernel-1)` to match valid Conv1d length.
- Residual + LayerNorm follow the usual Transformer block (no extra FFN, to keep the change local).

Unchanged: charsets, encoding, folds, MSE + Adam, early stop, metrics (CI / MSE / rm² / AUPR).

## Config

Added to every dataset spec in `data.py` (`ATTN_DEFAULTS`) and to CLI in `train.py`:

| Field | Default | Notes |
| --- | --- | --- |
| `attn_heads` / `--attn-heads` | 4 | Must divide `num_filters * 3`. Default 32 filters → conv dim 96 → 4 heads. Model snaps to the largest valid head count if needed. |
| `attn_dropout` / `--attn-dropout` | 0.1 | Dropout inside MHA |

New dataset `dummy` (smoke tests only):

| Field | Value | Why |
| --- | --- | --- |
| `path` | `deepdta-attention/dummy_data` | Generated by `make_dummy_data.py` |
| `is_log` | 0 | Affinities already on a pKd-like scale |
| `max_smi_len` | 40 | Short enough for CPU |
| `max_seq_len` | 60 | Must stay > `3*(seq_kernel-1)` after valid conv |
| `smi_kernel` / `seq_kernel` | 4 / 4 | Smaller than KIBA 8/12 so dummy lengths survive 3 convs |
| `aupr_threshold` | 7.0 | Dummy labels straddle ~7 |

KIBA / Davis kernel and length settings are unchanged.

CLI also gained `--dataset dummy`. Evaluate/predict must reuse the same `--num-filters`, `--embed-dim`, `--attn-heads`, `--attn-dropout`, and kernels as training.

## Other code changes

- Imports are local (`from data import …`) because the folder name `deepdta-attention` is not a valid Python package identifier. Run `python3 deepdta-attention/train.py …` from the repo root.
- Logs: `logs/deepdta-attention/<stamp>/`
- Checkpoints: `checkpoints/deepdta-attention/<stamp>/` (or `--out-dir …/checkpoints`)
- Model class renamed `DeepDTAAttention`.
